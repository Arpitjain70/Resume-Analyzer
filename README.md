# 🚀 ATS Resume Analyzer — AI-Powered Resume Scoring System

A full-stack, enterprise-grade Applicant Tracking System (ATS) Resume Analyzer built with **React**, **Spring Boot**, **Supabase PostgreSQL**, and **Google Gemini 3.6 AI**.

---

## 🌟 Key Features

- 🔒 **Secure User Authentication:** Stateless JWT authentication with BCrypt password hashing.
- 📄 **PDF Text Extraction:** High-accuracy PDF parsing using Apache PDFBox.
- 🤖 **AI-Driven Resume Analysis:** Integrates Google Gemini 3.6 AI to analyze resumes, score ATS compatibility (0–100), and highlight formatting or structural red flags.
- 📊 **Interactive Dashboard:** Beautiful score visualization breakdown, personalized improvements, parsed candidate info, and missing skill suggestions.
- ☁️ **Cloud Database & Storage:** Powered by Supabase Cloud PostgreSQL.

---

## 🛠️ Technology Stack

- **Frontend:** React 18, Vite, Tailwind CSS, Axios, React Router v6
- **Backend:** Java 17, Spring Boot 3.2.5, Spring Security, JWT (JJWT), Apache PDFBox
- **Database:** Supabase Cloud PostgreSQL
- **AI Engine:** Google Gemini 3.6 Flash (`generativelanguage.googleapis.com`)
- **Hosting & Deployment:** GitHub Pages (Frontend), Render (Backend), GitHub Actions (CI/CD)
